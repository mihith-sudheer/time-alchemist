# Time-Alchemist - Turn Free Minutes into Gold

An AI-powered micro-productivity assistant that takes the time you have (e.g., “I have 17 minutes”) and recommends optimal micro-tasks to boost productivity, focus, and well-being.

**Features**

-Smart time bucketing (1–3 min, 3–7 min, 7–15 min…)

-AI-powered task suggestions

-Clean recommendation logic

-Expandable architecture (web app, mobile app, personalization)

**Tech Stack**

-Python

-Rule-based logic / ML

-JSON task database

-Optional: Streamlit UI

**Project Structure**

│── data/

│   ├── bucketing.py

**Goal**

Help users turn small pockets of time into meaningful actions using smart task recommendation logic.
